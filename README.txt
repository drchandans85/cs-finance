CS FINANCE MOBILE V2

This version is designed for phone screens and installation as a PWA.

IMPORTANT: Do not open index.html directly from a ZIP/file manager if you want install/offline features.
The folder must be hosted on an HTTPS website.

HOSTING OPTIONS
1. Upload the contents of this folder to any static HTTPS host (for example GitHub Pages, Cloudflare Pages, Netlify, or your own HTTPS server).
2. Open the resulting HTTPS URL in Chrome/Safari.
3. Android/Chrome: use the Install CS Finance button or browser menu > Add to Home screen.
4. iPhone/Safari: Share > Add to Home Screen.

DATA
Data is stored locally in that browser/device. Use Backup JSON regularly. No banking credentials are required.
